# CLA signatures

This branch only holds the signatures of the [HVX Contributor License Agreement](https://github.com/baw-dk/hvx/blob/main/CLA.md).
The CLA workflow (`.github/workflows/cla.yml`) writes them to `signatures/version1/cla.json`
when a contributor signs on a pull request. See `docs/contributing/cla.md` on `main`.

Do not protect this branch: the workflow commits to it.
